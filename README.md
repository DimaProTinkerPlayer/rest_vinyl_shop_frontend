# Vinyl Shop Frontend

Клієнтська частина інтернет-магазину вінілових платівок із підтримкою JWT-автентифікації та розмежування прав доступу.

## Функціонал

* **Каталог (`index.html`)** — публічна сторінка для перегляду вінілових платівок (доступна всім користувачам).
* **Реєстрація (`register.html`)** — створення нового акаунта з клієнтською та серверною валідацією полів.
* **Авторизація (`login.html`)** — вхід у систему за допомогою JWT (`access` та `refresh` токенів), редірект на попередню захищену сторінку (`?next=`).
* **Керування магазином (`manage.html`)** — закрита сторінка для авторизованих користувачів (додавання платівок) та адміністраторів (створення нових жанрів).
* **Автооновлення токенів та Logout (`api.js`)** — автоматичний запит на `/auth/refresh` при отриманні `401 Unauthorized` та очищення `localStorage` під час виходу.
