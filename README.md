# Vinyl Shop Frontend

клієнт для демонстрації інтеграції з REST API інтернет-магазину вінілових платівок та роботи через CORS.

## Адреси та порти
- **Frontend:** `http://localhost:3000` (або `http://127.0.0.1:5500`)
- **Backend API:** `http://127.0.0.1:8000`

## Як запустити проєкт

Запустити локальний статичний вебсервер можна будь-яким зручним способом:

### (Python)
```bash
python3 -m http.server 3000
